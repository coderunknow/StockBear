  suite via tournament.py's seeded shuffle. Shards run as parallel isolated

  `scripts/pool_matches.py` (pairs are rebuilt per shard, then CR1-clustered

  clustered LCB95 must be strictly > +50.
- Forfeit/crash policy (predeclared, symmetric): a TIME_FORFEIT (clock
  exhausted) is a loss for the forfeiting side; engine crashes are forfeits
  for the crashing side; games unadjudicated at max-plies are excluded from

- No peeking: shard results are only pooled after ALL shards complete; the
