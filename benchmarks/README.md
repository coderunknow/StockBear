# Benchmarks

The executable embeds the versioned perft and search suites in `positions/`; `openings.txt` feeds the optional paired tournament tool. The committed `results/0.1.0-dev1/` files are an intentionally recorded small baseline, not fabricated example output or a runtime dependency. See [the report](results/0.1.0-dev1/REPORT.md) and [methodology](../docs/BENCHMARKING.md). External opponents and temporary build artifacts are not included.
